如何获取森空岛 Token

  1. 用浏览器登录 森空岛官网
  2. 保持登录状态，在同一浏览器新开标签页，访问： web-api.skland.com/account/info/hg
    （也可以登录 鹰角网络通行证 的同路径页面）
  3. 页面会显示一段 JSON，找到 {"content":"XXX"} 字段，复制 XXX 部分（不含引号）粘贴到上面的输入框
  4. 点击「绑定并签到」，插件会先验证 token，验证通过即完成绑定并立即签到一次
⚠️ token 等同于你的森空岛登录凭证：不要发到群聊或泄露给他人；
⚠️ token 会过期，签到失败时重新按上面步骤取一次新 token 再绑定即可；
⚠️ 也可以在 QQ 里私聊机器人发送 /skdlogin <token> 完成绑定（私聊绑定才能接收自动签到和理智提醒的私聊消息）。
